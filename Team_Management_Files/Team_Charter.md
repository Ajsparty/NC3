# NC3 Team Charter

**Repository:** https://github.com/Ajsparty/NC3

## Purpose
This charter outlines the purpose, structure, and working agreements for the NC3 project team analyzing Lansing's economic ecosystem and community wealth with the Lansing Growth Fund.

## Project Goal
Produce a practical, annually refreshable scorecard for Lansing's four largest institutional actors (the "Big 4"): Michigan State University, General Motors, State Government, and Local/Regional Governments. The scorecard estimates local employment, tax-base, and wealth-retention impacts using public data and clearly labeled stand-in measures.

## Repository
All project files, data, notebooks, and documentation are maintained in the GitHub repository at:

https://github.com/Ajsparty/NC3

Clone or fork from this URL. Keep the folder structure clear so collaborators can locate files quickly. See the root README.md for structure, naming standards, and install instructions.

## Team Roles and Responsibilities
- Maintain reproducible analysis pipelines and documentation.
- Contribute to shared notebooks, data files, and deliverables under the established folder structure.
- Follow file-naming standards (YYYYMMDD, MSU NetID or NC3 prefix).
- Update the root README when major folders or files change.

## Communication and Meetings
- Primary partner contact: Chris Miller (chris@nc3now.org)
- Meeting notes and weekly reports belong in this folder (`Team_Management_Files/`).
- Use clear, descriptive commit messages.

## Working Agreements
- Prioritize a public-data baseline scorecard with documented methodology.
- Treat dashboard and GIS features as stretch goals if scope expands.
- No NDA is currently expected; clarify terms before introducing non-public data.
